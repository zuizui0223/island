# v1 freeze

**Freeze date:** 2026-07-03

This branch preserves the first complete end-to-end analysis used to evaluate the island-floral-syndrome hypothesis. It is retained as an immutable baseline for comparison with the manuscript-ready reproducibility revision.

## Scope retained in v1

- Global island filtering, island-area and continent-distance workflow
- GBIF-derived *Bombus* environmental mismatch / PDI workflow
- Trait reclassification for flower colour, floral form, pollination guild, and self-incompatibility
- Animal-pollinated island-flora subset and tropical/temperate grouping
- Northern-temperate island-level Bayesian component/path-model comparison and regional projection

## Interpretation status

v1 is a **baseline analytical result**, not the final submission version. Subsequent work must preserve v1 unchanged and proceed in separately documented manuscript branches. Every substantive change to trait coding, source data, environmental inputs, or model specification must be recorded in a changelog and evaluated against this baseline.

## Next-stage objective

The next stage is not to broaden the hypothesis or add analyses. It is to build a provenance-tracked trait database, make the workflow executable from a fresh clone, and test whether the existing qualitative conclusion is robust to documented data-quality and implementation corrections.
