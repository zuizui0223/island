# High-yield mixed wave 8 checkpoint

This checkpoint adds seven individually reviewed species-direct records selected
from the latest formal Run 31747359040 support=2 `genus x trait_name` queue.
It prioritizes a third agreeing species, but only after checking exact accepted
identity, the individual trait, value polarity, cultivar scope, source lineage,
and contrary evidence.

Four rule-candidate rows cover Aegilops tauschii mating system, Pimenta pseudocaryophyllus
flower colour, Scolopia braunii
flower size, and Scleromitrion verticillatum flower colour. The Pimenta source
PDF was also rendered and visually checked on its species-treatment page.

Three further rows preserve counterevidence rather than cherry-picking only
agreement: Lyonia lucida and Anthoxanthum odoratum are self-incompatible, while
Oxytropis campestris is self-compatible in an independent experimental chapter
that conflicts with its existing direct SI record. These rows must enter normal
direct-conflict resolution and can invalidate proposed genus rules.

The recorded 60 potential cells are a queue ceiling, not coverage. The shared
all-evidence workflow must still apply source-lineage deduplication, direct
conflict resolution, dominance, masked validation, and leave-one-lineage-out
validation. This directory emits no genus inference.

Lilium longiflorum was rejected from the outcrossing rule-unlock set. Although a
2001 population study called it obligately outcrossing, a later 17-population
crossing experiment found substantial individual and population variation in
self-compatibility. A single outcrossing state would therefore be unsafe.

Cirsium palustre was also retained as pending rather than accepted. Plants
protected from insects produced seed, but the original study did not separate
self-pollination from apomixis, so it does not identify the requested autonomy
mechanism precisely enough for the strict ledger.

Likewise, genus descriptions, search snippets, cultivar evidence, trait
substitution, family inference, global fallback, and diagnostic n=2 rules are
not accepted as direct evidence here.

The same change excludes the pre-existing Aegilops tauschii High
`self_incompatibility=SI` record. Its saved excerpt names Hordeum bulbosum as
the self-incompatible species, so the Aegilops assignment is a cross-species
title/abstract extraction error.
