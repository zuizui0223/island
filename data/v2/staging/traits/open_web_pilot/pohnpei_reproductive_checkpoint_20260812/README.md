# Pohnpei reproductive checkpoint, 2026-08-12

This checkpoint adds 49 individually reviewed High evidence rows from 25
species in Chapter 2 of Yomai's 2021 University of Tennessee dissertation:
25 `self_incompatibility = SC` observations and 24 trait-specific
`autonomous_selfing_capacity` observations.

The source table retains all 36 dissertation rows. Eleven observations from
the Yomai & Williams (2021) experiment are excluded from this new lineage,
including two unmarked transcriptions, so the article and dissertation cannot
be counted as independent evidence. `Bidens pilosa` receives an SC row only;
its autonomous row is withheld because Table 2.1 reports no hand-self
denominator.

Autofertility states use the existing ledger thresholds: AFI >= 0.8 is
`autonomous`, 0.2 <= AFI < 0.8 is `mixed_or_variable`, and AFI < 0.2 is
`absent`. These thresholds affect only `autonomous_selfing_capacity`; SC is not
substituted across reproductive traits.

Every promoted row contains the stable repository URL, exact table statement,
retrieval date, official PDF SHA-256, source lineage, identity method, and a
line-by-line audit decision. No family inference, global fallback, n=2 formal
rule, axis-only join, or cross-trait substitution is used.
