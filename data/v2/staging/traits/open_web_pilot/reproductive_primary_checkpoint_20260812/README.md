# Reproductive primary-study checkpoint, 2026-08-12

This checkpoint adds individually reviewed, species-direct reproductive
evidence. Its largest input is the 60-species Konno et al. (1999) bagging
experiment. It also corrects two Paspalum title/abstract clause-leakage errors
with full-text evidence and records targeted primary-study evidence for
Platanthera lacera, Fritillaria imperialis, Viburnum lantanoides, and
Rhynchospora breviuscula.

`konno_1999_name_resolution_20260812.csv` records all 60 submitted names. Exact
accepted names are used directly. A synonym is accepted only when the 2026-08-12
GBIF species match and the WFO Plant List 2026-06 DwC snapshot resolve it to the
same species and family. Six ambiguous, fuzzy, rank-mismatched, or
backbone-discordant names remain rejected.

Every accepted candidate has a matching line-by-line audit record. Evidence
contains the original URL, retrieval time, exact or structured-table supporting
excerpt, original-study lineage, content fingerprint, and source-content hash
or explicitly identified excerpt-hash basis. No family inference, global
fallback, axis-only join, or cross-trait reproductive substitution is present.
