# Reproductive rule-unlock checkpoint (2026-08-12)

This checkpoint contains nine individually reviewed, species-direct High
records from six original-article lineages.  The species were selected from
the current unresolved acquisition queue because a third independent direct
species could establish a high-information `genus x trait_name` rule.  This
selection changes acquisition priority, not the inference thresholds.

Each row retains the accepted species, one specific reproductive trait, exact
supporting excerpt, stable source URL, retrieval time, content hash and source
lineage.  Dioecy and explicit outbreeding are stored only as `mating_system`;
bagging experiments only as `autonomous_selfing_capacity`; and explicit
compatibility statements only as `self_incompatibility`.  The formal shared
all-evidence rebuild decides whether a genus rule is eligible after direct
conflict and leave-one-lineage-out checks.

Sources:

- Castellani et al. 2024, *Nature Plants*, Rhynchospora breviuscula.
- Honma et al. 2003, *Horticultural Research (Japan)*, Vitis coignetiae.
- Men et al. 2021, *Frontiers in Genetics*, Vitis amurensis.
- Urfusova et al. 2021, *Preslia*, Elymus repens.
- Kawano et al. 2008, *Plant Species Biology*, Fritillaria koidzumiana.
- Mejias 1992, *Flora Mediterranea*, Sonchus microcephalus.

An Ornithogalum thyrsoides candidate was rejected: the retrieved experiment
compared conspecific hand pollination with controls but did not directly
demonstrate the claimed autonomous-selfing state.  Search snippets were not
used as evidence.  No family inference, global fallback, formal n=2 rule, or
cross-trait substitution is emitted by this checkpoint.
