# Rodger 2021 autonomous-selfing checkpoint

This package promotes measured pollinator-exclusion output for strict,
trait-specific `autonomous_selfing_capacity` evidence.

- 1,528 source rows inspected.
- 337 novel accepted/synonym-direct species x trait cells.
- 363 evidence rows from 206 original-study lineages.
- 338 exact accepted-name rows and 25 strict two-backbone synonym rows.
- 200 reproducibly hash-sampled reviews across 11
  source-dataset x state x name-match strata.
- Audit precision: 200 / 200 = 1.0; cultivar contamination: 0 / 200.

Existing direct species x trait pairs were not researched again. Family
conflicts, non-species names, and names lacking two-backbone agreement remain
in the selection audit. The evidence is High because each row is a
peer-reviewed database record of an experimental pollinator-exclusion
treatment and retains its original-study citation as `source_lineage`.

This source is expected to improve direct evidence and conflict diagnosis,
but its strict coverage gain must be measured by the GitHub artifact; the
package does not claim that every added direct row produces a new resolved
axis because new counterexamples may invalidate genus Low cells.
