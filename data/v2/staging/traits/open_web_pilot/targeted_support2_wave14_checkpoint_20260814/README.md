# Targeted support=2 wave 14 checkpoint

This checkpoint adds seven individually reviewed species- or synonym-direct trait rows from two independent source lineages. It targets support=2 `genus x trait_name` rules; no genus value is written here. The common all-evidence rebuild alone decides whether a candidate rule passes dominance, masked species validation, and source-lineage leave-out validation.

The UFPE thesis PDF was retrieved and hashed in full, and its relevant pages were rendered for visual review. `Calathea villosa` is stored under accepted name `Goeppertia villosa` only after exact synonym agreement from GBIF and WFO. The Gagea article excerpt was verified on the author-hosted full-text page and hashed as exact UTF-8 excerpt bytes.

The World Flora Online Cassipourea candidate was withheld after a second HTML-block audit showed that the regular-flower sentence is a genus description from a separate provider block. A species name elsewhere on the page was not used to turn genus-level text into species-direct evidence.

Search snippets were used only for discovery. The source page, exact excerpt, stable URL, retrieval time, content hash and lineage are retained for every accepted row. Same-study rows share one lineage and therefore cannot masquerade as independent sources.
