# Targeted support=2 wave 14 checkpoint

This checkpoint adds eight individually reviewed species-direct trait rows from three independent source lineages. It targets support=2 `genus x trait_name` rules; no genus value is written here. The common all-evidence rebuild alone decides whether a candidate rule passes dominance, masked species validation, and source-lineage leave-out validation.

The UFPE thesis PDF was retrieved and hashed in full, and its relevant pages were rendered for visual review. `Calathea villosa` is stored under accepted name `Goeppertia villosa` only after exact synonym agreement from GBIF and WFO. The Gagea article excerpt was verified on the author-hosted full-text page and hashed as exact UTF-8 excerpt bytes. The World Flora Online page is a Flora Mesoamericana treatment that explicitly identifies `Cassipourea elliptica` as the sole Mesoamerican species before stating that its flowers are regular.

Search snippets were used only for discovery. The source page, exact excerpt, stable URL, retrieval time, content hash and lineage are retained for every accepted row. Same-study rows share one lineage and therefore cannot masquerade as independent sources.
