# Wave48 multi-source reproductive unlock

Wave48 advances only previously unresolved reproductive-assurance cells from
the formal Wave47 artifact. It does not rescan the 106,295-species universe.

The packet contains four original sources, thirteen reviewed species-trait
rows, a strict WFO/GBIF identity audit, and an explicit rejection ledger.
Evidence remains trait-specific: autonomous self-pollination is not converted
to self-compatibility, and self-compatibility is not converted to autonomous
selfing or mating system.

Pelargonium supplies the only intended new genus rule. The Callicarpa row is a
counterexample that blocks an unsafe support-2 inference. Torenia and
Spermacoce rows add direct evidence, but their single source lineage cannot
pass leave-one-source-lineage-out validation and therefore cannot create genus
Low by themselves.
