## Non-negotiable comparisons
1. Fit on the same **raw `log(1+distance_km)`** scale, not separately standardized regional distances; compare **north-midlatitude slope minus tropical slope**, with spatial-block robust inference.
2. Main common support **0.2514927916–783.0170568 km** (four-region 5–95 percentile overlap fixed on Oct 5, NOT tuned here). Full-range is sensitivity, not a substitute for the matched test.
3. Main botanical scope is original strict `native_nonendemic` and source-evaluable accepted species (do not upgrade WCVP regional-native to island-native).
4. Preserve four GIFT source-assignment modes `geo_k5`, `geo_k10`, `geo_k20`, `geo50_climate10`; use `geo_k10` as descriptive anchor and all four as correlated sensitivities, not four independent replications.
5. Separate source prevalence expectation, genus composition, total source-relative sorting and within-genus sorting. Do not turn a within-genus residual into within-species evolution.
6. Rival SC-only model: conditioning on the *same islands' source-adjusted SC component* when testing floral traits, using either total-source correction or stricter within-genus correction. This is **not causal mediation**.
7. Unresolved if <50 islands, <10 physical blocks or <5 distinct first/source signatures per region; no relaxed thresholds after inspection. Report number of tested and untestable panels.
8. For a new beyond-Baker *pattern*, demand common-support within-genus floral effect after SC adjustment, explicit **between-region contrast**, multiplicity correction, and same direction in All + Direct and across source modes. To call it an **ecological channel rule** requires independent pollinator-channel evidence beyond this test; plant data alone cannot establish it.
