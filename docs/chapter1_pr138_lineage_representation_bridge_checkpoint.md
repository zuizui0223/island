## Question

PR #138 shows that most regional floral-accessibility geography is represented by genus composition, and that the exact-SI Palearctic attraction/accessibility slope does not exceed a genus-preserving source-pool null. This bridge asks the next non-causal assembly question:

> Given the genera supplied by the frozen mainland source pool, are genera with different mainland-derived floral functional positions represented non-randomly on islands as mainland distance increases?

The test does **not** infer historical source ancestry or a pollinator mechanism.

## Frozen functional coordinate

For each species with both frozen syndrome scores,

```text
functional_position = (-large_bee_like + generalized_accessible) / 2
```

Genus source position is the mean of this species coordinate among scored species occurring in GIFT mainland floras. The island outcome is never used to define this coordinate.

The all-analysis layer contains 5,806 species with a complete functional coordinate; 4,197 of them occur in the matched GIFT mainland source flora, yielding 749 source-position genera at the primary one-scored-species minimum. Requiring at least two scored GIFT source species per genus leaves 346 genera.

For the exact-SI sensitivities, the corresponding complete-coordinate / matched-GIFT counts are:

- all-analysis exact SI: 504 / 353 species, 157 source-position genera;
- direct-only exact SI: 197 / 194 species, 127 source-position genera.

## Source-availability matching

For each island and each frozen source definition (`geo_k5`, `geo_k10`, `geo_k20`, `geo50_climate10`), candidate genera are classified by:

1. the number of assigned source regions in which the genus occurs; and
2. in the primary design, source-species richness bin (`1`, `2`, `3–4`, `5–8`, `9+`).

Within each availability class the observed number of represented genera and the observed number of island species are held fixed. The expected functional position is the source-class mean. Therefore a positive enrichment cannot be generated merely by observing fewer genera, by preferential loss of low-prevalence source genera, or by a different source-species-richness distribution.

Primary matching is `prevalence_richness`; `prevalence_only` is a sensitivity.

## Decomposition

Three outcomes are kept separate.

- `entry_enrichment`: one vote per represented genus. This asks **which genera are represented**.
- `species_enrichment`: one vote per represented island species, using its genus's source functional position.
- `loading_increment = species_enrichment - entry_enrichment`: additional weighting generated by **how many species represented genera contribute**.

The models use the same PR #138 geography and baseline controls:

- `log_distance_to_continent_km`;
- `log_island_area_km2`;
- climate PCs 1–4;
- cluster-robust inference by `spatial_block`.

## Direct regional heterogeneity tests

The primary broad genus-entry response is not interpreted by comparing significance labels across regions. Direct clustered tests of the distance-slope difference were prespecified for the primary design.

### Northern-midlatitude vs Tropical

`Tropical - Northern` genus-entry slope differences are negative and FDR-supported in **8/8** source-mode × stratum scenarios, ranging approximately from `-0.1003` to `-0.0638`.

### Palearctic vs Neotropical

`Neotropical - Palearctic` differences are negative and FDR-supported in **8/8** scenarios, ranging approximately from `-0.1104` to `-0.0778`.

Thus the source-matched lineage-representation response itself is biogeographically contingent; this is not merely “significant in one region and non-significant in another.”

## Exact-SI decomposition

The exact-SI restriction changes **where** the lineage signal appears.

### All-analysis exact SI

For the primary source matching with the three-represented-genus minimum:

- genus entry: positive/FDR-supported in **1/8** Palearctic scenarios;
- species enrichment: **2/8**;
- loading increment: **7/8**.

### Direct-only exact SI

The stricter direct-only evidence layer gives the same decomposition boundary:

- genus entry: **1/8** positive/FDR-supported;
- species enrichment: **2/8**;
- loading increment: **7/8**.

Direct-only Palearctic loading slopes are positive in all eight scenarios (`+0.00753` to `+0.02041`); seven survive source-mode FDR. The sole support loss is native-nonendemic `geo_k5` (`q ≈ 0.0639`).

**Exact-SI interpretation:** after restricting to taxa with measured self-incompatibility, the signal is no longer consistently a binary “which SI genera enter” effect. It is concentrated more strongly in **species loading among represented genera**.

This does not contradict the existing genus-fixed null. The genus-fixed null asks whether the final SI assemblage slope exceeds what measured genus composition can reproduce; this bridge asks how that genus composition is built from source-supplied lineages.

## Chapter 1 → Chapter 2 connection

The supported Chapter 1 sequence is now more specific:

```text
isolation
  → region-specific source-available lineage representation
      → broad Palearctic: mainly genus entry
      → exact-SI Palearctic: stronger species loading within represented genera
  → floral accessibility composition
```

This provides a falsifiable empirical correspondence to the `izu-core` Chapter 2 result that post-reorganization response sign depends on starting functional position and realized partner/local context. It does **not** show that the same pollinator process generated the global lineage sorting.

The proper Chapter 2 bridge therefore remains:

```text
Chapter 1: starting lineage functional positions are filtered/loaded differently by region
Chapter 2: functional starting position × partner context × local filtering can generate conditional response signs
Empirical Izu gate: directly measure functional position → visitor exposure/effectiveness → reproductive outcome
```

## Claim ceiling

This bridge supports:

> Source-availability-matched lineage representation is itself associated with isolation in a biogeographically contingent way. In the broad Palearctic flora the strongest component is genus entry, whereas within exact-SI taxa the stronger surviving component is species loading among represented genera.

It does **not** establish:

- historical Bombus or other pollinator loss;
- pollinator-mediated colonisation or extinction;
- historical mainland source ancestry;
- in-situ floral evolution;
- differential diversification;
- the direction of causation between floral functional position and lineage persistence;
- that the synthetic `izu-core` 0–1 coordinate is already empirically identified by the Chapter 1 syndrome coordinate.

The next causal/empirical step belongs in the Izu bridge: predeclare candidate measurable plant–visitor functional-position axes and test them against single-visit pollen deposition before mapping any axis onto the `izu-core` response geometry.
