# Chapter 1 v13 submission figure sync — 2026-09-17

## Submission architecture

The current Chapter 1 submission uses **three main figures**. The paper is organized around one global question: does geographic isolation repeatedly shift island floras toward a common floral/reproductive island syndrome, and is that pattern aligned with increasing pollen limitation?

Earlier region-comparison and lineage-assembly analyses remain recoverable as historical or supplementary provenance but are not part of the current main-figure argument.

## Evidence-role labels

The submission uses the following labels consistently:

- **frozen primary / confirmatory parent result** — results already locked before the current synthesis;
- **frozen sensitivity / robustness** — previously locked alternative evidence scopes or model-form checks;
- **post-hoc functional triangulation** — the exact-species GloPL trait-state analysis added after the parent moderation results were known;
- **descriptive synthesis** — summaries of already fitted coefficients without a new inferential test.
