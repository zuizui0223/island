# FD × Chapter 1: corrected-isolation extension, frozen design before new outcomes

25 November 2026. An exploratory extension to PR #347, not a change to the GEB H1–H4 selector. The already observed FD results motivated the design; it is not a prospective confirmation.

**Source:** original progressive artifact 10058653212 (run 34232450884), own GBIF occurrence/status roster (4505 islands) and species-Direct ledger, SHA256-checked, plus the corrected geography table (8264 units) pinned to current Chapter 1. The 928 triple-eligible islands (2234 globally complete species) are a source gate, not the whole database. Historical “GIFT 4505” naming is not a replacement of the target roster. No mainland reference used in this new baseline.

**H1 extension:** identical carriers per endpoint; for the triple colour/form/symmetry set, equal-30 marginal Rao and actual-joint Rao (exact expected value under rarefaction, with-replacement Q convention), and mean 30 seeded rarefactions of excess mutual information of colour vs intact form/symmetry. MI null is exact hypergeometric fixed-margin expectation inside each sample, not a genus null. Pair sensitivity separately assesses colour/form, colour/symmetry, form/symmetry, symmetry/depth, form/depth with minimum 5 carriers and fixed-5 metrics; this is intentionally a coarse low-n estimand, not directly magnitude-comparable to n30. Report all support, all-recorded and literal-native subsets. No filling unknown labels, no inferred pollinator guilds.

**Models:** one island per row, region-specific OLS with distance, log area, four climate PCs using the identical corrected H1 columns. Predictors standardized within the model cohort; response remains Q or nats. CR1 spatial cluster covariance and finite t(G-1), minimum 50 islands, 10 blocks and full rank. Second fit adds log scored-carrier count and trait coverage. H2 extension reconstructs Direct selfing_core from the parent snapshot and existing score definition (minimum two informative components), requiring >=10 scored species per island, then compares distance slopes on IDENTICAL matched rows before/after score adjustment; separate sensitivity requires >=10 selfing-scored members among the actual triple-morphology carriers. Same-carrier means score carriers are among morphological roster, not that all species or the random 30 are scored. H2 is conditional decomposition, not mediation; no claim of reproducing the exact H2 frozen coefficient. WCVP sensitivity not substituted by strict native; the historical WCVP artifacts are not verified available in this check.

Multiplicity: fixed BH and BY family per scope × variant × triple/pair family; untestable slots count conservatively as p=1. No cherry-picking, no inference from differences in significance. Regional interactions, genus-preserving nulls, geography/repeated-species sensitivity and true local phenotype effects remain follow-up; cluster intervals do not remove cross-island shared species. Source-relative FD from earlier PRs is a different estimand, kept in the evidence ledger. Output anonymous aggregate JSON only, no island/species IDs. New results must be reviewed before updating evidence status.

Source implementation: scripts/fd_self_db_isolation.py; tests/test_fd_self_db_isolation.py; .github/workflows/run-fd-self-db-isolation.yml. Run on the integration branch; only source-verified successful outputs can be interpreted. No change to original submission files.
