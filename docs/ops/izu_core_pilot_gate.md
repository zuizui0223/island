# Izu Core-pilot gate

## Purpose

This note records an outcome-blind Phase 0.5 source-region assignment for six
Izu Islands. The change opens bounded Core-pilot work; it does **not** decide
flora membership, establishment, trait values, Bombus occurrence, pollination
service, or analysis inclusion.

## Source-region decision

The six frozen GSHHG island polygons are assigned to the already accepted
`temperate_japan_main_islands` source region. The assignment uses geography and
floristic-source context only. Dinerstein et al. (2017), Supplemental material
2, Table S1b, places Pacific Honshu and the volcanic Izu Islands in the Taiheiyo
evergreen-forest ecoregion (PA0440). This evidence is independent of the floral,
reproductive, Bombus-occurrence, and model outcomes.

Reference: Dinerstein, E. et al. (2017). *An Ecoregion-Based Approach to
Protecting Half the Terrestrial Realm*. BioScience 67:534-545.
[doi:10.1093/biosci/bix014](https://doi.org/10.1093/biosci/bix014).

## Required next operations

1. Build a reviewed flora anchor and taxon/establishment table for each island.
2. Run bounded trait-evidence discovery and produce coverage/attrition outputs.
3. Prepare the separate predeclared Apidae acquisition for these same frozen
   island polygons, then run effort-aware Bombus diagnostics.
4. Compare the resulting count of M1-eligible islands with the preregistered
   continuation thresholds before fitting any outcome model.

The six-island Izu set is a mechanism-development and feasibility pilot. It is
not, by itself, large enough for the preregistered global M1 claim.
