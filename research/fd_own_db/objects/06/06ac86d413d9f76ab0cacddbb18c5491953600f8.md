## Why this extra test was essential

In the preceding 500–2,000km, **no shared full-flora accepted species**, different physical 10° block source audit, the tropical n≥5 positive signal was reversed by block-disjoint matching. A different, very selective **northern-midlatitude** exploratory signal was positive in 199 block-disjoint matchings only when BOTH **absolute directly trait-known plant carrier count ≥10** AND **floral colour+form trait documentation fraction ≥10%** were required, but other coverage-selected subsets gave different signs. The **199 selections are not independent biological or regional histories**. Moreover, absolute n thresholds can change measured frequency dispersion.

The new hypothesis-free robustness test retains the FULL original **4,505** botanical-island population, and the original **1,464 n≥5 directly eligible northern-midlatitude** floras supply **2,732 distinct original measured flower-colour×form species** for a FIXED region-wide in-sample genus-exchange reference. Exactly the same **456 original species-disjoint eligible island pairs across 29 candidate physical blocks**, on the same n≥10 AND ≥10%-documented cohort, are used for original full carriers and **29 independently seeded without-replacement draws of EXACTLY 10 direct trait carriers from EACH focal island**. This changes observed carrier count without changing the region-source genus reference, island-pair geometry, source/identity mask or real accepted species-wide phenotype.

Each repeat is evaluated against the same **199 outcome-blind maximum-cardinality disjoint physical-block pair selections**, each using only **12** geographically non-overlapping source-pair dyads. These 29×199 values are repeated Monte Carlo sensitivity outcomes, **not** 5,771 independent island phylogenetic comparisons, randomized studies or a frequentist evolutionary p-value.

## Falsification, inference ceiling, and future validity gate

1. A coarse floral category-frequency differentiation residual beyond *one* regional in-sample genus permutation reference is a legitimate, **region-, support- and geography-dependent observational candidate** in the northern-midlatitude n≥10 / 10%-coverage island pairs. The same source globally shows no stable analogue in tropical source-block-independent matched n≥5 pairs.
2. **This is NOT confirmation of source-independent lineage filtering**. In-sample donor floral profiles include focal species; regional genus groups may have one measured profile; 10° geographic block independence does not separate candidate GIFT ancestral mainland source pools, islands may share phylogeny and phenotypes, and documented native plant origins are sparse for the short-distance outcome. Real local pollinators and pollen-transfer success are absent.
3. **There is no universal beneficial pollinator functional interpretation**. No island-specific flower colour/form adaptation is measured: the same accepted species retains exactly one whole-genus Direct floral record across the island population; the observed difference is floristic assemblage category membership and frequency.
4. Keep **full 4,505 islands and ten separately Direct-recorded traits + three genuine two-trait endpoints as the paper's primary dataset**. Do not replace the global population with these 12 matched pairs. This small cohort is an adversarial identification gate, not a new narrowed universe.
5. Before any new biological mechanism claim, require out-of-island and source-archipelago heldout genus donor calibration on the SAME target plants, independent phylogenetic/ancestral source histories, nonrandom trait documentation propensity, and identical-plant effective field pollinator evidence if interpreting partner loss. If these are unavailable, publish the descriptive floral category diversity and turnover results with these sensitivity bounds, not a causal pollination syndrome.
