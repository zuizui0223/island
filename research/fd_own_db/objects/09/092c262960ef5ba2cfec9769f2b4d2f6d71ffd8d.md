## Direct ecological question

Earlier direct original accepted botany genus-shared deficit versus exact finite native GIFT source name exchangeability was stable after holding the taxon name's GIFT source listing breadth and REAL distance to an actually listing candidate GIFT mainland SOURCE REGION (not plant point occurrence). This new study asks whether that result is an artefact of the **selection of the nearest FIVE geographical mainland GIFT regions** as source pool.

Compare TWO independent, actual original source-ranked lists:
1. `geo_k5`: five geographically closest source regions, 41,325 original island×native GIFT region assignments across the original 8,265 GIFT island identities (including all original botanical flora targets), REAL `source_distance_km`, climate_distance **not available**.
2. `geo50_climate10`: TEN climate-nearest native GIFT source regions drawn from 50 geographical neighbor candidates, 82,190 original island×source region rows, REAL separate source_distance_km and climate_distance, covering **4,485/4,505 original botanical floras** (20 original botanical floras have no such source candidate ranks).

These are distinct source species sets: expanding from five to ten native GIFT mainland region lists changes candidate count and regional plant taxonomy. Do NOT treat climate-distance as an observed continuous response or use the actually missing geo_k5 climate-distance values. The method calculates source-to-island MINIMUM original measured GIFT `source_distance_km` only among original selected mainland source regions that ACTUALLY list each named accepted species; do NOT call that the native source population's closest geographic range edge, a propagule dispersal distance or a pollen visitor channel.

For **each original source mode independently**, constrain original accepted island source-listed group and unrecorded candidate mainland group to observed GIFT accepted names and condition original EXACT finite-source GENUS shared richness null on (a) the accepted taxon's count of distinct native GIFT source region listings (five original breadth categories), (b) its MIN selected source-region km (four predeclared distance bands) and (c) actual focal/candidate accepted named plant counts in each cross stratum. Actual original botanical genus names are used, but **no flower phenotype Direct state** enters the genus sharing outcome. Original distinct native/nonendemic source status is strict; all island source-listed accepted species include introduced and unresolved statuses as a nonindependent **documentation comparator**. A genuinely paired result compares climate10 minus geo5 on the **SAME original island ID** only; source candidate taxa vary between modes, so cannot be called a within-species climate-selection treatment.

## Scientific interpretation

The original **negative direct taxonomic genus-sharing deviation from source-name exchangeability** is not a quirk of using the exact geographically five-nearest GIFT native source-region list: it appears with a substantially different climate-similar candidate source list too. This strengthens the observation of **nonrandom recorded floristic taxonomic composition relative to specified native GIFT potential mainland source names**, with full GIFT listing breadth, source REGION distance and native-source sample size conditioning. It does NOT prove adaptive island evolution, biological dispersal failure, establishment filtering, source pollen limitation or a plant-specific bee-to-moth/bird pollinator shift, because candidate source plants have no independently documented actual seed arrival, true geographically nearest native occurrence, source biomass, realized access or plant-specific trait fitness.

The all-status botanical flora null is deliberately not an indigenous plant replicate, since GIFT native/introduced origin is unresolved on 83.65% of original island×accepted-species flora rows. Strict native-known subset is much smaller and nonrandomly documented. The candidate source mode is NOT an experimental exposure and geographic conditional bootstrap intervals are descriptive for source category sampling, NOT phylogenetically independent adaptation cases.
