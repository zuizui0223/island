# 2026-11-15 — Direct decomposition of island–mainland candidate floral difference by source-congeneric genus turnover

**Design fixed before reading the NEW original decomposition outcome.** This is a posthoc study of previously discovered source-relative differences, not a confirmatory new independent hypothesis, and is NOT a predictive-accuracy model.

**Population and source:** preserve all 4,505 protected original GIFT island botanical floras, 10 independently species-Direct high/medium flower/reproductive traits, and the seven previously named morphology/reproductive sectors (zygomorphic, tubular/bell, open radial, deep tube, strictly SC, strictly autonomous vs absent, real same-species zygomorphic×tubular/bell), without a 928-island triple-complete gate. Strict native AND nonendemic AND floristic-native_nonendemic labels are required. Candidate mainland source species come only from the five original geographically nearest *native GIFT mainland source checklists*; exclude EVERY accepted species already recorded in the focal island's ENTIRE botanical flora before comparison. The local set contains original strict native_nonendemic Direct species **also listed** in the same five candidate source regions. Original status/source/trait names never leave the protected island CI.

**Direct response:** an actually documented **island-native category fraction minus unrecorded native mainland candidate category fraction**; not an ML predictive accuracy change, actual colonization success, arrivals, historical extinction or local adaptation. Exactly the same originally source-listing-breadth-balanced island cohort and original five bins `[1], [2–3], [4–10], [11–30], [31+]` as the previous verified original result #43712369169. Within an island and matching bin b, keep ALL source-Direct eligible accepted species and the original weight `h_b=min(n_native_b,n_source_b)` if both groups nonempty; use `h_b/sum_b h_b` to aggregate. Require >=5 native species and >=10 source-only candidate species on the endpoint before matching, and matched effective h>=5. Never weight a species that was not actually directly coded as a surrogate zero.

**EXACT complete source-label algebra:** Within original island i, source-breadth bin b, let `w_Ng=n_Ng/n_N` and `w_Sg=n_Sg/n_S` be the actual genus shares among Direct species, `q_Ng`, `q_Sg` the observed binary trait frequency among accepted names in genus g in the respective groups; both labels fixed ORIGINAL Direct. Let G_shared be genera actually present in BOTH groups in that SAME island/bin. Then

`Delta_ib = sum_shared[(w_Ng-w_Sg)*(q_Ng+q_Sg)/2] + sum_shared[(w_Ng+w_Sg)*(q_Ng-q_Sg)/2] + sum_native_only[w_Ng*q_Ng] - sum_source_only[w_Sg*q_Sg]`.

These four SIGNED terms must exactly sum to `observed fraction native minus source` for each source bin and island, and the breadth-matched sum must exactly reconcile the prior original 2026-11-15 breadth-match response (test tolerance 1e−12). Both the shared-genus composition term and within-shared-genus category-difference term can be positive or negative; exclusive-genus terms are signed. Do NOT divide the signed parts into simplistic causal fractions of colonization vs evolution or crop out negative components. In particular an endemic plant's phenotypic adaptation cannot be estimated from globally species-fixed genus values. Track each island's actual number of shared genera, native-exclusive and source-exclusive genera, proportion of DIRECT carriers in shared genera, and number of shared genera with different trait state across group species.

**Uncertainty:** original physical 10-degree island spatial block equal and first-GIFT-candidate-source-region group equal summaries, including 999 group-resampled descriptive 95% intervals, on each of four components and the total for precisely the SAME supported original islands. If <30 islands/<10 distinct group IDs, report NOT IDENTIFIABLE rather than use the positive sample. Across 4 defined GSHHG geographical regimes plus the single geography-unresolved island, all seven original binary endpoints reported, including weak/negative/nonidentified ones. Original island×plant rows, repeated taxa across islands and genus-level phylogenetic relatedness do not yield independent evolutionary histories.

**Interpretation:** `shared_genus_composition` is a difference in the relative abundance of directly recorded genus members across candidate floras, not specifically establishment. `shared_genus_within` represents different ACTUAL species-wide category labels within identical genus names, not in-situ phenotypic evolution; plant lineage divergence and category annotation quality remain possible. `native_exclusive_genus` and `source_exclusive_genus` are differences in genus documentation in the focal (native) checklist versus regional potential source candidates, not verified absence from the true island/native seed rain. Source listing breadth is a proxy for original GIFT catalogue availability, not real measured geographical distribution, arrival probability, or botanical provider-independence.
