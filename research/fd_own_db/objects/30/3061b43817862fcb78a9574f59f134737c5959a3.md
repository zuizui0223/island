## Scientific estimand and near/far identification

The study's macro population is all **4,505 GIFT original botanical island floras**; **4,450 original Direct distinct accepted species** carry both a real directly documented **floral form × floral symmetry** category state on the SAME accepted species. Isolate only source-specific eligible islands with at least **5 real same-plant form×symmetry carriers**; do not require flower colour or the former 928 three-trait/30-species complete-case.

For one same-broad-region island pair with different independently mapped original 10° spatial blocks and **ZERO shared accepted botanical species in the two FULL original GIFT checklists**, let the "far" island have at least twice the **(1 + distance_to_continent_km)** of its "near" partner. This is isolation from continents, not chronological extinction or actual ancestral propagule source. Original botanical floras with missing physical geography remain in the global study denominator, not assigned zero isolation.

Only when original far flora observed profile richness **k_far < k_near** is a genuine strict subset (far_profile_set properly contained in near_profile_set) mathematically possible. If both k are identical, subset means IDENTICAL sets; **do not call that directional loss**. Crucially the condition k_far<k_near is an outcome-defined filter, so the **separate genus-conditioned null MUST use ALL originally outcome-blind eligible pairs without this k filter**.

Three logically different references are reported and must not be pooled:
1. Exact **uniform fixed-k** original-region observed-profile null: P(far set subset of near | kfar<knear) = C(knear,kfar)/C(K,kfar) where K is region's real documented form×symmetry category combination count. It does NOT preserve source category prevalence, genus or phylogeny.
2. Exact **frequency-weighted fixed-k** original-region source profile null: probability of drawing k unique source-observed profile states whose subset is near's real observed set when each possible unique k-state combination has weight proportional to the product of its regional original unique accepted-species frequency counts. This is precisely defined, but **not** sampling a verified ancestral flora.
3. One-sided **conditional in-region genus** reference on ALL outcome-blind qualified island pairs: near observed category profiles are HELD FIXED; for each genus represented among far's measured real accepted species, draw exactly its original far Direct species count WITHOUT replacement from the original same-region measured same-genus taxa while maintaining complete original joint form×symmetry state pairing. The exact probability that all resulting far species profiles belong to the actual near observed profile set is a product of finite-population within-genus combinatorial terms. This does **not** hold far's observed k fixed and is NOT a joint permutation of both near and far taxa; it asks a different question from null 1/2 and cannot be interpreted as true independent within-lineage adaptation. The reference INCLUDES the study's species, not independent ancestral mainland trait observations.

All original candidate pairs are summarized descriptively without treating millions of reused pairs as biological replicates. A second source sensitivity uses **199 alternative outcome-blind maximum-cardinality, spatial-block-disjoint selections**. Each selected pair uses unique physical 10° blocks (40 northern-midlat, 44 tropical, 17 southern-extratropical all-distance pairs); the 199 re-selections are NOT independent phylogenetic histories, source lineages or statistical bootstrap confidence intervals.

## Interpretation: region profile prevalence, not necessarily selection

**Positive measurable property**: accepted plant floras have real, region-specific nested categorical form×symmetry profile relationships even when actual plant species are entirely disjoint; fixed-k uniform random source profile null severely underpredicts strict subsets, because original morphological profiles have drastically unequal prevalence. This is a distinct, meaningful recorded categorical ecological assembly result that cannot be represented by indiscriminate continuous 17D KDE volume.

**Major falsification**: regional observed profile-frequency weighting greatly increases the expected subset rate, and regional genus-conditional one-sided expected far-into-near compatibility is not stably exceeded under spatially nonreused block matching. Thus the original data **do not demonstrate** an independent isolation-driven selective loss of tubular/bell/zygomorphic floral specialist sectors, ancestral profile extirpation, local pollinator guild collapse or adaptive simplification. The earlier original marginal floral sector and rare-category absence analyses show related documented morphology changes, but do not turn this comparison into a measured functional pollinator syndrome.

**Source and inference boundaries**: physical island distance and different 10° blocks do not demonstrate independent source phylogenies, geologically independent origins or time direction. In-region genus null includes focal records; spatial block re-selections are not independent biological replicates. The original same-species species-wide global trait records are not island-specific observed flower phenotypes or pollen fitness, so no direct evolutionary mechanism is identified.
