## Main biological inference and hard limit

**Positive result retained:** conditional genus-linked flower category information transfers across geographically separated GIFT island plant floras in 8 original Direct endpoints. This suggests broad lineage-associated information survives floristic turnover, while the region-local vs region-external flora genus reference changes predictability in opposite directions between north midlatitudes and tropics for floral FORM (main original three-region report).

**But NOT a mainland ancestry result:** the original native GIFT mainland source list is an independently listed *candidate floristic opportunity*, NOT independent observed floral phenotypes of historical colonists. The same source Direct trait ledger is species-wide, so strict accepted species name holdout can eliminate nearly all original measured source joint profiles. The conditional other-island-genus model knows actual island genera, and the candidate mainland source model uses different source candidates, endpoint and original island cohorts: **their Brier/logloss magnitudes must not be subtracted**. The native-only and distance-selected source diagnostics cannot be claimed to independently generalize over the entire 4,505-island population.

**Interpretation for macroecological manuscript:** frame as **globally repeated botanical functional category repertoire, broad genus-associated trait predictability and regionally contingent source/reference composition**. Separately report **mainland-specific prospective trait/source identifiability FAILURE** for the actual 3,606 candidate source Direct-pair trait species under whole-flora name exclusion (9 for tested 2,324-island cohort; ZERO when all 4,505 original island names excluded). Don't conflate a mainland source candidate plant presence with the ancestral phenotype or a directed island pollinator shift. A real test requires independent mainland measured trait values on genuinely non-shared accepted species or actual population/phylogenetic origin data; further observational transformations of the same GIFT Direct species-ledger cannot create that information.
