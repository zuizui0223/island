## Why the genus-conditioned null is necessary

Six PREDECLARED actual high/medium species-Direct joint trait endpoints are the Cartesian *analysis targets*, but observed data come ONLY from the SAME actual accepted species records, not from synthetic A and B values belonging to different species:

- Floral FORM × self-incompatibility / autonomous selfing;
- Floral SYMMETRY × self-incompatibility / autonomous selfing;
- TUBE DEPTH class × self-incompatibility / autonomous selfing.

For each target original island, the externally learned congeneric source categorical predictor is P(A,B) = Σ_g P(g|geography) P(A,B|g, other island floras). The initial null factorizes the predicted whole mixture, **P(A)P(B)**, holding the mixture's global observed reference marginals exactly fixed. But *genera with different A and B frequencies can create pooled correlation even when all genera have internally independent A and B*. A superior joint predictor versus global P(A)P(B) could then merely show taxonomic assembly, not independent floral/reproductive coordination.

The stronger original source null instead uses:

\[
P_{\mathrm{genus-null}}(A,B)=\sum_g P(g\mid \mathrm{source\ geography})P(A\mid g)P(B\mid g)
\]

Each genus's own distinct A/B marginals, source geography-predicted genus probability, original name blacklists and the external-blind category fallback for unsupported/unknown genus are held fixed; ONLY **within-genus source joint dependence** is removed. This contrast asks whether learning congener floral structure×reproductive assurance **joint** P(A,B|g) predicts held-out REAL target island species better than learning independent P(A|g) P(B|g). It still is a SOURCE PREDICTION test, not a causal natural-selection or phylogenetic coevolution test.

**Positive predeclared gate**: actual joint model must have lower paired multiclass Brier AND log loss than its own-marginal factorized comparator, with **both** signed proper-score 499-bootstrap exploratory intervals entirely positive under **both** independent 10° physical block and first GIFT candidate-source group clustering. Retain negatives, ambiguity and insufficient original ecological source support; there are no independent factorial pollinator visitors/fitness responses here.

## Scientific interpretation and next falsifying tests

**Supported as a substantive negative:** under this strict full-accepted-name/source-region holdout, the available externally scored other-island congener floral-category *joint* data do not convey reproducible source information beyond simpler component predictions, even after allowing between-genus source floral/reproductive covariance. This qualifies any broad island "architecture×selfing channel syndrome" or globally integrated floral coordination claim. Two evolutionary mechanisms remain theoretically possible—initial genotype/trait covariation and selection—but neither is identified here.

**Critical limits:** Original 36 panels share accepted species across overlapping traits and source geography; sample fractions are documentation-selected. **19/36** lack independent source group support, and Southern literal native has **none**. "No predictive gain" cannot be interpreted as "no biological within-genus correlation", "no historical pollinator selection", "no island selfing adaptation" or "no same-island syndrome". There are no independent pollinator identities, effective flower visitation, pollen quantity, reproductive fitness, ancestral mainland trait measurements or phylogenetic direction of change. Loss intervals are *exploratory unadjusted*, not formal equivalence tests.

**Next test that could isolate true ecology**: obtain a same-accepted-species within-island versus mainland floral/reproductive trait *paired* dataset and independently sampled local pollinator community/fitness observations, then use phylogenetically structured source-heldout differences / matched island ancestry to discriminate establishment assembly from actual morphological adaptation. Without such source support, a global DRAFT mechanism is not confirmed by predictive success alone.
