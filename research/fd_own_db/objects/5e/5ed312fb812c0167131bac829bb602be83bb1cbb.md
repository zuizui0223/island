# Tropical island pollinator-guild filtering — frozen first-stage contract (2026-11-24)

## Question
Does geographic isolation filter the available pollinator fauna differentially, with butterfly and nectar-feeding bird opportunity declining more slowly than native bee opportunity in tropical islands? Does this composition, rather than total richness alone, predict the observed floral functional repertoire? This is a hypothesis, not an assumed ranking of dispersal ability or proof of replacement.

## Crosswalk and denominator
Before outcome analysis freeze independently matched spatial entity IDs, archive IDs, geography, taxonomic scope and data-quality flags. Treat one-to-many or multi-island unions as their original entity, aggregate all three sources and flora to the same entity or quarantine. No centroid-only join, no ambiguous name fallback. Separate tropical |lat| <=23.44 from existing macroregion definition; sensitivity uses existing source strata. Primary population for H1/H2 is the same independently source-qualified island entities for each compared pair of guilds, not selected positive outcomes. Publish coverage for all 305 bee entities and 4,505 GIFT frame. No matching based on floral outcomes. Report all unresolved and differing source dates. Explicit zero allowed only if original source supports complete guild coverage; positive-only checklists without certified zero and model no-overlap are not zero.

## Frozen analysis order
1. H1 differential isolation: on the same certified tropical island cohort, fit count GLM with guild-specific log area, climate/source-pool and log2(1+distance_km) slopes, archipelago/geography clustered uncertainty. Primary contrasts beta_butterfly - beta_bee and beta_nectarbird - beta_bee; two-sided intervals and Holm across both; sensitivity with genus/species coverage, source pool, nearby stepping-stone islands and alternative geographic blocks. A positive contrast does NOT require absolute increase. Compare identical cohorts only; no significance by comparing separate p-values. Butterfly range and bee checklist estimates not interchangeable; replicate on checklist-only data.
2. H2 relative retention: estimate within-guild regional source retention (observed native taxa / source-pool taxa where exact pool membership is independently supported), not raw bird:bee richness ratios (different global richness). Retention difference and log-ratio only when estimable; report sensitivity to zero and source denominator. Within-guild measured dispersal traits (AVONET HWI; independently sourced butterfly/bee traits), not taxonomic labels alone. Island source turnover is not historical replacement.
3. H3 floral shape: test prespecified direct same-species outcomes radial x deep and bilateral x deep (also colour only if actual same-species joint data exists). Binomial counts with denominator scored species, genus composition and source pool conditioning, geography, climate, richness/coverage and taxon/archipelago weighting. Test alternate guild contrast while holding overall available animal richness / guild-standardized total opportunity. No interpretation of radial x deep as unambiguous bird or butterfly syndrome. Use held-out geography for model evaluation. Do not condition primary ecological contrast solely on predicted genus weights. Separate SC and autonomous selfing.
4. H4 functional compensation: on same cohort, test joint nominal category Q and occupancy/turnover after rarefaction/coverage sensitivity, as well as actual joint trait pair frequencies vs genus-conditioned independence null. Predefined interaction between guild composition and total opportunity; no Gaussian KDE as definitive volume. Retention of flower architecture at equal total opportunity is an association, not pollen delivery. Require independent plant-visitor / pollen transfer observations for efficacy or historical shift.
5. Negative controls: non-nectar birds, unavailable flower trait/annotation quality, latitude/biogeographic source, matched source geography, independent tropical realms, oceanic/continental separately only if adequate support; leave archipelago out. Minimum 30 distinct common island entities and 10 independent archipelagos/blocks for primary slope contrast; report no supported effect if inadequate. Larger 4,505 botanical frame remains in manuscript. No post hoc threshold selection to force a positive.

## Status

No H1-H4 ecological effect, no cross-guild linked island denominator, no causal or historical pollination transition has yet been established.
