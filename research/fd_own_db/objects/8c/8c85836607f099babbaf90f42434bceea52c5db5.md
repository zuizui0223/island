## Direct taxonomic question, not a genus predictor or seed-arrival model

Earlier exact original GIFT source-name exchangeability analyses found **shared botanical GENUS deficit** and **within-island concentration of source-listed plants in the same genus**. They condition on n actual source-listed strict nonendemic native island species and n original unrecorded native GIFT candidate source species, within original five *GIFT listing breadth* bins; but did not explicitly condition on the source REGION'S geographic distance to the particular island. Both actual native source-list and source-only candidate taxa have original geographic opportunities that could differ.

The original SHA-pinned island_source_assignments.csv.gz has real `source_distance_km` for **all 41,325** original geo_k5 physical-island-to-ranked-native-GIFT-mainland-source region matches (8,265 candidate islands, five source regions each), including all original 4,505 botanical floras. Each original candidate plant accepted name is actually documented in one or more of those five source regions; its geographic source proximity is the **MINIMUM real source_distance_km only among those source regions actually listing the accepted plant name**. This is geographic distance to a broad potential GIFT mainland SOURCE REGION, **NOT** distance to a verified population occurrence, dispersal kernel, propagule arrival probability or ancestral native source. The original candidate source ranking is nondecreasing in source_distance_km for this geo_k5 mode, independently audited. The independently archived climate_distance value is **MISSING for all geo_k5 source rows** and not fabricated here.

The new comparison is an EXACT finite-population source-name random draw holding:
- **same exact original island accepted botanical species and original GIFT native source candidate lists**; source-only names are absent from the island's ENTIRE recorded accepted botanical flora, not necessarily biologically absent;
- **same exact GIFT listing breadth** in 5 prespecified source-native-mainland-entity-count bins: 1, 2–3, 4–10, 11–30, >=31;
- **same original taxon nearest candidate SOURCE distance in km** in 4 frozen bands [0,250), [250,750), [750,2000), [2000,infinity);
- **same source-listed focal accepted species sample size and source-only candidate sample size in each of up to 20 joint breadth×km classes**;
- the ACTUAL name/genus identity of accepted original native and candidate taxa, drawing focal species names without replacement from the unchanged original total candidate union and computing exact analytic expectation of shared, focal-only, source-only genus richness and genus pair concentration.

The previous **breadth-ONLY** original finite-source expectation is RECOMPUTED on **precisely the SAME PLANT NAMES surviving the joint geographic-distance matching**. This is important: it does not manufacture an attenuated effect by comparing entirely different plant taxa or sample sizes across the two null models. Source botanical accepted plants without a flower Direct trait are INCLUDED, so none of the morphological documentation selection is needed for the genus-count outcome. Preexisting 7 flower/reproductive Direct category masks are used only to retain the **SAME physical islands** for independent source-botany genus taxon checks.

## What geographical adjustment changes, and what it does NOT

**Robust observational result:** even when the genuine geographic distance to candidate native GIFT source REGIONS is explicitly fixed alongside species-name native GIFT listing breadth and taxon counts, actual recorded native island botanical species share fewer genera with potential unrecorded candidate mainland plant species than a fixed-opportunity random source name assignment predicts. The distance-only source opportunity explanation removes **only a modest part** of the original genus-sharing deficit in most region/scope cohorts, while the genus concentration result also survives.

**Critical limitations:** Candidate GIFT native mainland region centroid/proximity is a very coarse approximation to actual species range-to-island nearest edge. This null does not preserve dispersal syndrome/seed size, animal transport, wind/ocean currents, actual propagule arrivals, source biomass, island vegetation survey effort, taxonomic phylogenetic history, local phenotype evolution, flower trait documentation on all source candidates or actual effective pollinators. Repeating different original geographically overlapping islands does not create independent evolutionary trials. None of these source-list/non-exchangeability departures proves a failed plant establishment mechanism, adaptive island syndrome, selected flower loss, or functional pollinator channel shift.

**WCVP independent-native-range feasibility ceiling:** a historical WCVP-native TDWG-L3 range archive in original source Actions #32559322028 covers **53,475** original accepted plant names with native range claims, but only **24,395/221,994 ≈11%** of source GIFT mainland candidate species have this SELECTED archived range evidence; exactly the strict native-status source itself was partly assigned using WCVP original native ranges. Thus restricting the global null to these archived WCVP-matched taxa would add serious source/status selection. A new complete independent native TDWG-L3 range ledger for all candidate source names and actual point occurrence data would be needed to test true biological distribution constraints.

**Separate alternate source definition:** Original source assignment also contains `geo50_climate10`, climate-nearest 10 region entities from a geographic nearest 50, with 82,190 archived island×source ranks and valid climate-distance field (unlike geo_k5). This is a DIFFERENT candidate source flora and is independently being tested as a sensitivity of the original source-list construction, not falsely treated as a climate covariate for the identical geo_k5 candidate name set. The original 4,505 main GIFT floras and source trait original status must remain visible in all denominators.
