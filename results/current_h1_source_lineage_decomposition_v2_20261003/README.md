# Literal additive source-lineage decomposition of current H1 — 2026-10-03

## Question

Does the current seven-response tropical H1 in strict source-backed native
non-endemics arise through source-available genus entry, extra species loading within
represented genera, finer-grained species trait composition, or some combination?

This analysis uses the same four frozen GIFT source-assignment modes and
`prevalence_richness` matching used by the historical lineage-representation bridge,
but the response is now the **literal current H1 binary trait state** for each atomic
outcome.

## V2 repair

An initial current-H1 bridge (v1) retained the historical all-island-species weighting
inside represented genera. That was appropriate for the old scalar lineage bridge but
was not algebraically identical to current H1, whose denominator is the trait-resolved
species for each outcome.

V2 therefore uses only trait-resolved, source-candidate native non-endemic island
species and enforces the exact identity

```
raw H1 mean
= source-availability-matched expectation
+ genus-entry enrichment
+ within-genus loading
+ within-genus trait residual
```

before interpreting any component.

## Closure gates

Both exact closure gates passed.

- all-analysis:

  - maximum row identity error = **1.11e-16**;
  - maximum regression-slope identity error = **6.59e-17** across 28 atomic identities.
- Direct-only:

  - maximum regression-slope identity error = **1.04e-16** across 24 atomic identities.

Tolerance was 1e-12.

## Result: the hierarchy is antagonistic, not serial

The source-evaluable strict native-nonendemic subset does **not** reproduce a uniformly
positive current-H1 direction. Its raw joint vector is FDR-supported in all four source
modes in both evidence scopes, but the arithmetic mean of the oriented atomic slopes is
negative in every source mode.

### Source-availability-matched expectation

The expected source-genus component is directionally positive in every source mode:

- all-analysis mean slope: **+0.00637 to +0.01019**;
- Direct-only: **+0.00702 to +0.00798**.

However the joint vector is not FDR-supported in all four modes
(maximum q = 0.799 all-analysis; 0.495 Direct). This is directional evidence, not a
promoted source-pool mechanism.

### Genus entry

Genus-entry enrichment points in the **opposite** direction in every source mode:

- all-analysis mean slope: **-0.01392 to -0.01013**,
  joint vector FDR-supported in all 4 modes (maximum q = **0.01287**);
- Direct-only: **-0.01649 to -0.01467**,
  negative in all 4 modes but not 4/4 FDR-supported (maximum q = **0.07951**).

Thus current H1 is not generated by preferential entry of more H1-like source genera in
this strict tropical native-nonendemic source-matched frame.

### Within-genus loading

Additional species weighting within represented genera is small and not directionally
stable. Although the all-analysis joint vector is nonzero in all four modes, its mean
slope changes sign. Direct-only is not 4/4 FDR-supported. There is no promoted
within-genus loading route.

### Within-genus trait residual

The finer-grained species-trait residual is the only component with a robust positive
Direct-only pattern:

- mean slope **+0.00132 to +0.00286** in all four source modes;
- joint vector FDR-supported in all four modes;
- maximum q = **0.02048**.

The strongest positive atomic component is autonomous selfing
(beta approximately +0.0267 to +0.0310 across source modes; P = 0.0035–0.0049).
Actinomorphy and generalized form also point positive; plain colour,
self-compatibility and shallow/open tube point negative in this restricted frame.

All-analysis is close but does not pass the 4/4 FDR rule for the within-genus trait
residual (maximum q = 0.05726).

## Interpretation

The current H1 source-matched decomposition is therefore a **counter-gradient**:

1. source availability tends, on average, toward the H1 direction;
2. realized genus entry shifts against that expectation;
3. extra species loading contributes little consistently;
4. Direct-only species trait composition within represented source genera shifts back
   toward the H1 direction.

Because these components oppose one another, none should be labelled the single
generator of the global H1 recurrence. In particular, the robust Direct-only
within-genus trait residual is **not** evidence of within-lineage evolution. It can still
reflect within-genus species sorting, persistence, unmeasured source structure or true
evolutionary change.

This result replaces the initial v1 current-H1 entry analysis for scientific
interpretation. The older historical scalar lineage bridge remains valid for its frozen
estimand but is not the current H1 decomposition.
