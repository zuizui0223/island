# WCVP regional-native sensitivity on corrected geography

This surface replays Chapter 1 H1 using the 24 September 2026 corrected
spherical-coastline geography and a conservative regional-native sensitivity.
Unresolved island-species rows are upgraded only when the focal island maps
unambiguously to a TDWG Level-3 unit that WCVP lists in the accepted species'
native range. Source-backed introduced rows are never overwritten.

The analysis is a status sensitivity, not a claim of exact island-level nativeness.
Raw WCVP bulk bytes are not committed; the exact SHA256 and extraction manifest
are retained here.
