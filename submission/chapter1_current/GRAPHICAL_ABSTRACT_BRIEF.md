# Graphical abstract brief — Ecology Letters

## Core visual

A three-edge **constraint–response triangle**.

```text
                    geographic isolation
                     /                \
                    /                  \
                   v                    v
      floral/reproductive          pollen limitation
        response (H1/H2)              (H3)
                   \                    /
                    \                  /
                     v                v
               lower current pollen limitation
              for response trait states (H4)
```

The historical causal arrow

```text
past pollen limitation -> selection/sorting -> present trait composition
```

should appear as a dashed, explicitly unresolved edge rather than as an inferred pathway.

## Minimal labels

- **Isolation**
- **Reproductive assurance**
- **Floral accessibility**
- **Pollen limitation**
- **Historical causation unresolved**

## Visual rule

Do not use bee/butterfly/bird icons as causal agents. H1–H4 do not identify one realized pollinator mechanism globally.
